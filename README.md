# Coffee-Shop-sales

☕ Coffee Shop Sales Dashboard
📌 Project Overview

This project provides an interactive Excel Dashboard for analyzing coffee shop sales performance. It helps visualize key business metrics such as total sales, customer footfall, product performance, and sales trends across different timeframes and store locations.

The dashboard enables decision-makers to quickly identify sales patterns, top-performing products, and customer preferences, supporting better operational and marketing strategies.

🚀 How to Use

Open the Excel file containing the dashboard.

Use slicers (Month, Day, Size) to filter and explore data.

Analyze trends in sales, product categories, and customer behavior.

Use insights for decision-making regarding promotions, product stocking, and staffing.

📈 Business Use Cases

Identify best-selling products to optimize inventory.

Analyze peak sales hours to plan staffing.

Compare location-wise performance for expansion strategy.

Track customer preferences by size & category.

Monitor weekday sales trend for marketing campaigns.

📌 Conclusion

The Coffee Shop Sales Dashboard provides a data-driven approach to monitor business performance and support decision-making. It highlights top-performing products, customer trends, and location-wise sales, enabling the coffee shop management to maximize revenue and improve customer experience.
